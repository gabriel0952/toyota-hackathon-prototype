# 團隊範例畫面對齊與服務流程優化

更新：2026-09-07

以 `docs/團隊素材/` 的 16 張範例為基準，延續 TOYOTA 紅、白底、車款照片、五階段診斷、報告分頁、LINE 綠色頂欄、顧問側欄及名單結構。正式操作元素使用 HTML 元件，不使用圖片中的文字或 CSS 偽元素充當標題。

| 入口 | 對齊與優化 |
| --- | --- |
| `/driver` | 車主情境主視覺、三個核心問題、診斷入口、可操作的服務導覽及手機選單 |
| `/driver/diagnostic` | 五階段步驟（四步輸入＋分析）、車種卡片、可編輯車款與持有年數、補電方式、選填區域、單一數字輸入、可略過的能源資料 |
| `/driver/report/report-main` | 真實 DOM 標題、路徑摘要與完整度、三項阻力及分數刻度、充電／生活／成本／條件模擬分頁 |
| `/driver/booking/:reportId` | 車主專用諮詢／試駕表單、必要欄位、手機格式、聯繫同意與完成回饋；不再導向內部後台 |
| `/line` | 邀請→單題互動→官網；今天略過會結束本次邀請，停止提醒會保留停止狀態，可主動重新開啟 |
| `/line/result/:reportId` | 報告摘要卡片與完整報告入口，沿用相同手機框架 |
| `/advisor` | 狀態統計、篩選、姓名／車款搜尋、無結果狀態、工作重點；確認家充後名單同步顯示新狀態 |
| `/advisor/reports/:reportId` | 正確車主識別、區域資訊、確認條件、問句、工作階段內服務紀錄；勾选確認後才可建立新版 |

## 展示資料邊界

- 這是前端 prototype。沒有接入 LINE Messaging API、顧問登入權限、真實預約、充電站即時 API 或診斷模型。
- 表單草稿、LINE 偏好、顧問確認與紀錄使用此分頁的 sessionStorage，重新整理後保留；預約聯絡資料不儲存也不傳送。
- 診斷儲存介面會收到各階段實際輸入，報告仍使用明確標示的固定情境。初步填答不再顯示能源試算，避免在資料尚未確認前分散注意力。
- 地圖為固定離線示意底圖，輸入區域不會重新定位；台中目的地另列為圖外長途目的地。
- 家充「模擬結果」與顧問「條件確認」分開呈現；均不代表施工核准或正式報價。
- `present=1` 隱藏 Demo 控制。開發模式的「重設」同時清除新增的展示草稿、偏好與紀錄。

## 檢查方式

`pnpm lint`、`pnpm build`、`pnpm test`、`pnpm test:e2e`。

瀏覽器回歸包含桌面 1280×720、手機 390×844、1440×900 報告可見性，以及 13 個頁面／狀態的橫向溢出檢查。重點互動涵蓋填答保留、異常步驟網址、LINE 略過與恢復、車主預約、顧問搜尋／空狀態／紀錄／家充確認、灰色情境和條件模擬。

各入口截圖輸出於 `artifacts/screenshots/aligned-<width>-*.png`。


## 2026-09-07 第二次互動調整

- 首頁和報告摘要改用 TOYOTA 官方 bZ4X 實車背景，桌面為橫向白色漸層，手機為向下漸層；圖片接縫落在漸層的白色區域。
- 停車頁改成停車條件／補電方式卡片與區域表單。「沒有固定工作地點」免填公司，常去地點改為選填。固定示意地圖改為即時條件摘要。
- 行程頁提供數字輸入、滑桿和常用值，區分單程通勤與單日長途。沒有通勤、幾乎沒有長途時，停用或隱藏不適用欄位，送出值也一併調整。
- 能源頁提供直接輸入、常用金額／里程，以及不確定選項。空值或超出範圍顯示提示並阻止前進；未知資料暫不試算，不使用隱藏的舊值估算差額。
- 費用以同一比例尺比較，明確顯示可能多花或少花；試算方法放入可展開說明。底部操作列在捲動時保持可用。
- 表單新欄位仍使用本分頁草稿，報告仍為固定展示情境，不宣稱真實診斷。
- 新增無固定工作地點／通勤、無長途、油資未知、費用增加和輸入驗證回歸案例。完整流程共 22 項瀏覽器測試。


## 2026-09-07 第三次調整：減少填答負擔（取代上一版表單互動）

依使用者回饋，上一版同時提供滑桿、數字、快捷值、摘要與圖表，反而增加操作與閱讀負擔。

- 安裝使用者指定的 UI UX Pro Max skill，來源 `nextlevelbuilder/ui-ux-pro-max-skill`，固定版本 `4aad0584d92131626b16d4ff4d77f0455385013c`，個人安裝位置 `~/.codex/skills/ui-ux-pro-max`。
- 針對 progressive disclosure 的搜尋未得到相關資料庫結果；設計採用 skill 本身 quick-reference 的漸進揭露、單一主要操作、可見標籤、離開欄位後驗證與草稿保存指引。React 搜尋確認使用 controlled inputs。
- 停車與充電先只選補電方式，提供「還不確定」。停車條件與生活區域收入原生 details，全部選填；新的草稿不再預填虛構區域。
- 行程只保留通勤距離與長途頻率。移除精確最長里程與補電停留時間，這兩個舊欄位不再提交。未固定通勤可略過，取消略過時恢復原輸入。
- 能源頁每個答案只有一個數字輸入，油資與里程可分別略過。移除滑桿、快捷值、右側摘要和即時費用圖表。
- 操作列回到正常文件流，不遮住手機內容。錯誤在離開欄位後顯示，透過 aria-describedby 連結；未知值不以隱藏數字送出。草稿仍在返回與重整後保留。
- 新增 375、768、1024、1440 px 的三頁截圖及溢出檢查、鍵盤展開選填區域、略過與恢復、錯誤時機回歸。截圖位於 `artifacts/screenshots/simplified-<width>-step-<step>.png`。

報告仍是固定展示情境，這次沒有改動判斷模型，也保留官方 Toyota 實車背景與漸層。
